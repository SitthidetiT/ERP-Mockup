# ERP Company Platform (Mockup)

ต้นแบบ Next.js ภาษาไทยสำหรับสาธิตกระบวนการของบริษัทผลิตชิ้นงาน ข้อมูลลูกค้า ราคา เอกสาร และพนักงานทั้งหมดเป็นข้อมูลสมมติ ไม่มี backend หรือการส่งอีเมลจริง

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` (หรือพอร์ตที่ Next.js แสดง) ข้อมูลจำลองจะอยู่ใน `localStorage` กด **รีเซ็ตข้อมูลสาธิต** ในแถบข้างเพื่อเริ่มใหม่

คำสั่ง `dev` และ `build` ใช้ Webpack เพื่อรองรับเครื่องที่ `node_modules` เป็นลิงก์ไปยังตำแหน่งอื่น หากยังพบข้อความ `Symlink [project]/node_modules is invalid` ให้ตรวจว่ากำลังรันคำสั่งจากโปรเจกต์นี้และไม่ได้สั่ง `next dev` โดยตรง

## เส้นทางสาธิต

หน้า Dashboard มีทางลัดสี่สถานการณ์:

1. **A งานปกติ:** สร้างใบเสนอราคา → ตรวจอีเมล `.example` → จำลองการส่ง → บันทึกตอบรับ → เปิดงาน → วิศวกรรม → แบบ → PPC → เบิกวัสดุ → ผลิต → QC ผ่าน → แพ็ค → จัดส่ง
2. **B ส่งกลับแก้ไข:** เปิดงาน `JOB-2609-003` → QC ไม่ผ่านพร้อมจำนวนเสียและเหตุผล → ฝ่ายผลิตแก้ไข → ส่งตรวจซ้ำ → QC ผ่าน ประวัติเดิมยังอยู่
3. **C จ้างภายนอก:** เปิดงาน `JOB-2609-002` → บันทึกส่งจ้าง → รับกลับ → เบิกวัสดุ → ดูต้นทุนจ้างแยกในแท็บต้นทุน
4. **D HR:** ยื่นใบลา → สลับเป็นผู้บริหารเพื่ออนุมัติ → ปฏิทินแสดงวันลาที่อนุมัติ

ตัวสลับบทบาทด้านบนใช้ดูเมนู ข้อมูล และปุ่มที่แต่ละฝ่ายเข้าถึงได้ บทบาทผู้บริหารเปิดดูและกดสาธิตได้ทุกขั้นตอน

## หน้าที่สร้าง

- Dashboard, กล่องงานของฉัน, การแจ้งเตือน และทางลัดสี่สถานการณ์
- ระบบกลางและสิทธิ์, ลูกค้าและใบเสนอราคา, รับงาน, วิศวกรรมและแบบ, PPC, จัดซื้อ, คลัง, ผลิต, QC, แพ็คและจัดส่ง, ต้นทุนและรายงาน, HR
- รายละเอียดงานกลาง 11 แท็บ พร้อมประวัติการเปลี่ยนสถานะ
- แบบฟอร์มจำลองใบเสนอราคา การส่งอีเมล รีวิว วางแผน จ้างภายนอก รับ/โอน/เบิกวัสดุ ตรวจ QC และใบลา

## ขอบเขตที่ยังเป็นตัวอย่างเพื่อหารือ

- การอนุมัติคำขอซื้อ การกำหนดสิทธิ์ซีเคร็ต และกฎการเร่งงานยังเป็นข้อความ/flow ตัวอย่าง รอยืนยันกับฝ่ายที่เกี่ยวข้อง
- สูตรต้นทุนจริง สัดส่วนงานทำเอง/จ้างภายนอก และความหมายของแต่ละ Store รอยืนยัน
- เอกสารและรูปชิ้นงานเป็นไฟล์สาธิต ไม่มีระบบอัปโหลดหรือการส่งออกเอกสารจริง
- เวลาเข้างานเป็นรายการตัวอย่าง ไม่มีการเชื่อมเครื่องลงเวลา

หน้าจอเหมาะกับเดสก์ท็อปและแท็บเล็ต การเปลี่ยนสถานะทั้งหมดเกิดในเบราว์เซอร์เท่านั้น
